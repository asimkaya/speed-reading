# Test metinleri

Hepsi kamu malıdır (yazarlar ölümlerinin üzerinden 70 yıl geçmiş). Kaynak: Vikikaynak. Wiki işaretlemesi temizlenmiş düz metindir.

**Ana demo metni: `kurk-mantolu-madonna-berlin.txt`** (Sabahattin Ali, ö. 1948). Neredeyse hiç konuşma içermeyen, sürükleyici anlatı. Diğerleri (Ömer Seyfettin, ö. 1920) diyalog yoğun olduğu için sadece tokenizer/duraklama testlerinde kullanılır.
